# Environment Variables

This service uses the following environment variables:

- `PORT`: HTTP port for the API gateway (default: 3000)
- `CORS_ORIGIN`: Allowed CORS origin (default: http://localhost:5173)
- `AUTH_SERVICE_HOST`: Hostname of auth-service for TCP connection (default: localhost; set to auth-service.railway.internal on Railway)
- `AUTH_SERVICE_PORT`: TCP port of auth-service (default: 8877)
- `PLAYER_DATA_SERVICE_HOST`: Hostname of player-data-service for TCP connection (default: localhost; set to player-data-service.railway.internal on Railway)
- `PLAYER_DATA_SERVICE_PORT`: TCP port of player-data-service (default: 8878)
- `ADMIN_SERVICE_HOST`: Hostname of admin-service for TCP connection (default: localhost; set to admin-service.railway.internal on Railway)
- `ADMIN_SERVICE_PORT`: TCP port of admin-service (default: 3006)
- `CLOUDINARY_CLOUD_NAME`: Cloudinary cloud name
- `CLOUDINARY_API_KEY`: Cloudinary API key
- `CLOUDINARY_API_SECRET`: Cloudinary API secret
- `CLOUDINARY_URL`: Cloudinary URL

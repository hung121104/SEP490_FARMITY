# Environment Variables

This service uses the following environment variables:

- `MONGO_URI`: MongoDB connection string (default: mongodb://localhost:27017/game)
- `PORT`: TCP port for the microservice (default: 8877)
- `JWT_SECRET`: Secret key for JWT signing (default: REPLACE_WITH_A_STRONG_SECRET)
- `ADMIN_CREATION_SECRET`: Secret key for admin account creation (default: ADMIN12345)
- `REFRESH_TOKEN_TTL_DAYS`: Refresh token time-to-live in days (default: 7)
- `SESSION_INACTIVITY_MINUTES`: Admin session inactivity timeout in minutes (default: 60)
- `RESEND_API_KEY`: Resend API key for sending OTP emails
- `MAIL_FROM`: Sender name and email (must be from a verified domain in Resend, e.g. `FARMITY Admin <no-reply@yourdomain.com>`)
- `REDIS_HOST`: Redis host for analytics presence cache (optional; analytics uses Mongo fallback when unset)
- `REDIS_PORT`: Redis port (default: 6379)
- `REDIS_PASSWORD`: Redis password (optional)
- `REDIS_DB`: Redis logical database index (default: 0)
- `REDIS_TLS`: Enable TLS for Redis (`true`/`false`, default: false)
- `REDIS_KEY_PREFIX`: Prefix for analytics Redis keys (default: farmity:analytics)
- `HEARTBEAT_OFFLINE_TIMEOUT_SECONDS`: Seconds without heartbeat before player is marked offline for concurrent (default: 25)
- `HEARTBEAT_LEGIT_MINUTES`: Cumulative heartbeat-confirmed minutes needed to mark session legit (default: 5)
- `ADMIN_SERVICE_HOST`: Hostname of admin-service for TCP connection (default: localhost; set to admin-service.railway.internal on Railway)
- `ADMIN_SERVICE_PORT`: TCP port of admin-service (default: 3006)

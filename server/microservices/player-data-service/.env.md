# Environment Variables

This service uses the following environment variables:

- `MONGO_URI`: MongoDB connection string (default: mongodb://localhost:27017/game)
- `PORT`: TCP port for the microservice (default: 8878)
- `AUTH_SERVICE_HOST`: Hostname of auth-service for TCP connection (default: localhost; set to auth-service.railway.internal on Railway)
- `AUTH_SERVICE_PORT`: TCP port of auth-service (default: 8877)
- `ADMIN_SERVICE_HOST`: Hostname of admin-service for TCP connection (default: localhost; set to admin-service.railway.internal on Railway)
- `ADMIN_SERVICE_PORT`: TCP port of admin-service (default: 3006)
